# simple_pic12_pdip8_universal_devboard
A simple development board with an LED and GPIOs on Pin headers.  includes an ISP Header and selectable dual power supply with a screw terminal

## Project Structure
- **/hardware**: Contains the KiCad schematic and PCB layout files.
- **/firmware**: Contains the Microchip MPLAB  C/ASM source code.
